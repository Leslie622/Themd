# Themd 项目地图

> 本文件是 Themd 的唯一架构事实来源。修改目录、数据流、平台接口、持久化协议或开发命令时，必须同步更新本文件。

## 1. 项目定位与当前状态

Themd 是本地 Markdown 笔记本（仅 Tauri 桌面端，Web 路线已清除）：CodeMirror 编辑、markdown-it 预览、可视化主题工场、图片内嵌、Markdown/HTML/PDF 导出。**Folder-first「打开目录为工作区」**：目录即笔记本，树完全镜像磁盘，每个笔记都是工作区内的文件（Typora 语义）；编辑防抖写回、外部改动经递归监听自动重载（双向同步，文件即事实来源）。

当前为分层架构：笔记和主题由 Controller 管理，IndexedDB、文件、字体、窗口、PDF 均通过平台契约访问（platform 层只有 Tauri 实现）；旧 Store 文件只保留兼容导出入口，编辑器与外观偏好属于 UI 会话状态。新代码不得把 Zustand、IndexedDB 或 Tauri API 作为领域事实来源。

## 2. 运行时矩阵

单一环境:Tauri 2 桌面端。React + CodeMirror + markdown-it;笔记快照存 IndexedDB(WebView2 内)+ 文件绑定写回;文件对话框为 Tauri dialog + Rust 文件命令;字体由 Rust 枚举系统字体;PDF 走 WebView2 PrintToPdf。

开发端口固定为 `1420`，由 `vite.config.ts` 和 `src-tauri/tauri.conf.json` 共同约束。

## 3. 目标架构

```text
React UI
  → application controllers / use cases
  → domain models and pure functions
  → repository / platform contracts
  → IndexedDB, browser APIs, Tauri IPC
```

前端领域模块按功能文件夹：

```text
src/app/                 应用组合、服务初始化、UI 会话
src/modules/notebook/    笔记/文件夹领域、Controller、仓储
src/modules/themes/      主题领域、Controller、仓储
src/modules/editor/      编辑器偏好与 CodeMirror 行为
src/modules/rendering/   Markdown、主题编译、独立 HTML 文档
src/modules/export/      导出用例
src/platform/            Web/Tauri 能力适配
src/shared/              事件、通用类型、跨模块工具
src/components/ui/       shadcn 基础组件，只放通用 UI
```

## 4. 依赖方向与禁止依赖

- `domain` 只能依赖类型和纯函数，不得依赖 React、Zustand、DOM、Tauri。
- `application` 只能依赖 domain 和 platform contracts，不得直接调用 `indexedDB`、`localStorage`、`invoke`。
- `platform` 实现 contracts，可依赖浏览器 API、Tauri API 和 Rust 命令。
- `components` 通过 Controller、hooks 或 platform services 工作，不得裸调用 `invoke`。
- 业务事件使用 `AppEventBus` 或显式 props；禁止新增 `window.dispatchEvent` 业务事件。
- `src/store.ts`、`src/store-themes.ts` 是迁移兼容入口，新功能不应继续扩展它们。

## 5. 核心数据流

### 编辑与预览

```text
CodeMirror onChange
  → NotebookController.updateNote
  → NotebookSnapshot
  → IndexedDbNoteRepository.save(themd/notebook/v1)
  → preview debounce
  → renderMarkdown
  → ThemeCompiler
  → PreviewPane
```

预览区右侧大纲窄栏（TOC）：`modules/rendering/outline.ts` 的 `buildOutline` 复用 `md.parse` + `slug` 提取标题（id 与渲染 HTML 同源，跳转直接 querySelector）；窄栏可折叠（`useEditorPrefs.outlineEnabled`），滚动 rAF 前向扫描高亮当前标题（只读，不干扰 sync-scroll）。

### 文件绑定双向同步

```text
写入向:updateNote / bindNoteToFile
  → 500ms 防抖 → FileLinkGateway.writeTextFile → Rust 原子写(tmp + rename)
  → lastWritten 记录内容,用于抑制自家写回触发的 watcher 回声
读取向:Rust notify 对工作区根**递归**监听 → 防抖 300ms
  → emit 'fs-changed' → FileLinkGateway.onFsChanges → handleFsEvents
  → modified:与当前内容一致或为自家回声则忽略;干净静默重载;
    有未写回编辑则发 fs-conflict 事件,UI 弹窗二选一(重载磁盘版/保留本地写回)
  → removed:标记 fileMissingIds(继续编辑写回自动重建并解除)
  → renamed:改绑 sourcePath,非自定义标题跟随文件名
落盘时机:500ms 防抖、Ctrl+S(活动笔记立即写回)、窗口失焦/切后台 flushAll、
  托盘退出前 Rust 发 'app-before-quit' 并 sleep 600ms 留写回窗口
写回失败:经 appEvents 'write-failed' 通报 UI toast(带「重试」= flushNote),
  同一文件只报首次、写成功后解除;失败保留 dirty 状态(下次编辑/重试继续写),
  不另建重试队列
```

**打开工作区**：侧栏工作区胶囊 → 系统目录选择器（或最近列表重开）→ `openWorkspace(root)` = Rust `read_folder_notes` 递归读取 .md/.markdown/.txt（非 UTF-8 不入库）→ 整表替换笔记列表（同路径笔记按 sourcePath 复用，id/笔记主题跟随，重扫不丢状态）→ 重建文件夹（目录去重）→ `watchWorkspace(root)` 递归监听。工作区记忆（current + 最近 5 个）在 `themd/ui-workspace/v1`，启动时自动重开。**新建笔记** = `createNoteInDir`（工作区根或右键指定文件夹）：`unique_destination` 求无冲突路径 → 立即写盘绑定，不再有「未绑定笔记」概念（v≤3 的库内笔记在 hydrate 时按用户决定丢弃）。**另存为**（顶栏 Save 按钮 / Ctrl+Shift+S）= 选新位置重新绑定（复制语义，原文件经确认可删）；失联笔记借此自救。**绑定换目录时图片随迁**（统一在 `bindNoteToFile` 内，组合根注入 `src/lib/note-assets.ts`）：正文引用的 `assets/…` 图片按「旧笔记目录 → 全局图片根」的顺序用 `read_binary_file` + `write_image_file` 原样字节复制到新笔记目录（目标同名跳过幂等、单张失败不阻塞）。冲突处置入口在 `NotebookController.reloadNoteFromDisk` / `keepLocalNote`。

### 文件夹 = 目录（Typora 文件树模型，仅桌面端）

```text
归属:绑定笔记 ∈ 其所在目录的文件夹(派生,不存 folderId)
不变式:publish 时惰性补建「绑定笔记目录 → Folder 实体」
移动到文件夹:记 wasDirty → cancelPendingWriteBack → migrateNoteAssets(图片随迁)
  → move_note_file(重名自动后缀) → 改绑 sourcePath;脏笔记立即补写新路径(编辑随笔记走,
  抢在 watcher 事件前落盘抑制回声);未绑定笔记 = unique_destination 求路径后走
  bindNoteToFile 写盘绑定(移动即绑定,图片随迁同走 bindNoteToFile)
重命名笔记:绑定笔记 = rename_note_file 同目录改名(重名自动后缀) → 标题/路径跟随实际落点;
  未绑定笔记仅改显示名。绑定笔记标题恒等于文件名(内容编辑不派生标题)
  → 有未写回编辑的笔记立即补写新路径
删除笔记:绑定笔记 = trash_file 把磁盘文件移入系统回收站(可恢复,幂等);
  未绑定/失联笔记仅从应用移除。外部删除:干净笔记直接从列表移除(树=磁盘),
  有未写回编辑的标失联走横幅自救
外部新建:Create 事件映射为 modified,前端按路径找不到笔记 → 工作区内
  的 .md/.markdown/.txt 自动入库(标题=文件名,整棵递归)——树=磁盘实时视图
外部目录重命名:watcher 报目录级 renamed(单文件事件不会来),
  按「严格位于 oldPath 之下」批量换算 folders + notes(路径相等 = 单文件,走文件级)
```

设计决定：**删除文件夹 = 删除磁盘目录**（对齐 Typora 文件树，用户确认后经 `delete_directory` 移入回收站），其下子文件夹与笔记从应用一并移除——文件已不存在，笔记不能留着假装还能编辑；空文件夹照常显示（空文件夹在文件树里就是可见的）。路径比较一律经 `src/shared/paths.ts` 的 `normalizePath`/`isPathUnder`（大小写 + 分隔符不敏感），展示保留原串。

### 工作区（folder-first）

```text
打开:侧栏胶囊/空态 CTA → pickDirectory → openWorkspace(递归导入+递归监听)
记忆:themd/ui-workspace/v1 {current, recents[≤5]};启动自动重开,重扫按
  sourcePath 幂等复用笔记 id
清除:closeWorkspace → watchWorkspace(null) + 清空笔记列表
新建:工作区根(顶栏/侧栏「新建」)或文件夹右键「在此文件夹新建笔记」,
  都走 createNoteInDir(unique_destination + 写盘绑定)
```

工作区外不存在笔记:watcher 只递归监听工作区根,`importExternalCreated` 仅收根下笔记扩展名文件;「导入文件/文件夹」按钮已随库内模式一起删除(目录即笔记本,文件放进去就出现)。

### 图片

图片存储三模式（`themd/ui-preferences/v1` 的 `imageMode`，默认 `assets`）：
- **本地文件夹（默认，仅桌面端）**：图片**原样字节**落盘（不重编码，保真优先）写入 `${assetsRoot}`，正文引用 `assets/<名>-<随机8位>.<原扩展>` 相对路径；`assetsRoot` 空 = 平台默认（桌面端应用数据目录 `appDataDir()/assets`），**绑定磁盘文件的笔记例外**——插图落笔记自身目录下 `assets/`（随文件走）。落盘经 FileGateway.`writeBinaryFile` → Rust `write_image_file`（`Vec<u8>` IPC 二进制）；`tauri.conf.json` 的 `assetProtocol`（scope `**`，绑定笔记的图片可来自任意用户目录）供 `convertFileSrc` 渲染，`src/lib/image-src.ts` 在 markdown 渲染时把相对路径同步改写为 asset:// 地址（`initImageSrcResolver` 于 main.tsx 预取）：绑定笔记的相对路径（`assets/…`、`./x.png`、`sub/x.png`）一律相对笔记自身目录解析（App 在活动笔记切换时经 `setActiveNoteDir` 注入基准），库内笔记仅 `assets/` 相对全局根。设置里可改目录/恢复默认/打开目录（opener 插件）；编辑器内 Ctrl+点击 assets/ 路径在文件管理器中定位图片。
- **上传图床（remote）**：压缩（长边 1600/WebP 0.82）后上传拿外链，正文写 `![alt](https://…)`；失败即中止该张插入，不回落。服务商二选一（`uploaderProvider` + 各凭据字段，token 明文本机保存，Typora/PicGo 式）：
  - GitHub 仓库：`PUT repos/{repo}/contents/assets/{name}`（token 需 Contents 读写权限，取 `content.download_url`）
  - PicGo 本地桥：`POST {picgoUrl}`（默认 `127.0.0.1:36677/upload`），body `{list:[{base64,fileName}]}`——用户在 PicGo 里配任意对象存储
  - 上传协议统一在 `src/platform/web/uploader-gateway.ts` 纯函数（`uploadWith` 注入 fetch）；Tauri 实现注入 tauri-plugin-http 的 fetch（Rust 层请求绕 CORS，capability 白名单 api.github.com/127.0.0.1/localhost），Web 实现注入原生 fetch（GitHub 实测 `Access-Control-Allow-Origin: *`，Web 端可用）。contract 在 `src/platform/contracts/uploader-gateway.ts`。配置 UI 在设置抽屉的 `UploaderField`（`src/components/settings/UploaderField.tsx`，FontField 式槽位：触发器回显当前配置，服务商/凭据/测试上传收进 Dialog；SM.MS/s.ee 路线已在偏好 v6 移除，存量 provider 回落 github）。
- **内嵌（可选）**：压缩为 data URL 内嵌正文，单文件自包含。
- 编辑器徽章（`src/lib/image-decorator.ts`）只隐藏 data URL，相对路径/外链直接显示文本；预览/导出对三种形式均原样输出，`<img>` 相对路径按应用根/导出位置解析。
- **预览区图片灯箱**（`src/components/ImageLightbox.tsx`）：笔记预览（`PreviewPane`）与主题工场完整预览（`ThemeStudio` 的 `ThemeScopedPreview`，`compact`/`inspect` 模式不启用）里点击 `<img>` 事件委托打开全屏灯箱（`collectLightboxState` 收集全部 `<img>` 并按被点图定位）——可在同一篇的多张图之间左右切换（‹ › 箭头/方向键）。第三方库 yet-another-react-lightbox + Zoom/Captions 插件：纯滚轮缩放（`scrollToZoom`，上限 4x 图片像素尺寸，注意 `maxZoomPixelRatio` 不能传 -1，会把 maxZoom 算成 1 导致缩放按钮永远 disabled；`minZoom: 0.5` 放开缩小下限，默认 1 = 初始即最小不能缩；`wheelZoomDistanceFactor: 800` 让每格滚轮约 ±20%，默认 100 一格就 ×2；滚轮缩放走 rapid 分支无库动画，由 `image-lightbox.css` 给 `.yarl__slide_wrapper` 的 transform 加 150ms transition 补平滑；拖拽平移仅当图片放大到超过视口才有余量（`changeOffsets` 钳制，YARL 正确行为）、`carousel.padding: 64px` 让初始 fit 四周留白不铺满视口、双击放大、`closeOnBackdropClick` 点空白关闭、Esc/关闭按钮；**旋转/下载为自定义工具栏按钮**——旋转按 slide 序号记忆（90° 递增，transform 写在 `.yarl__slide_image` 上与 wrapper 的缩放/平移互不干扰，换一组 slides 复位），下载走 fetch→blob 触发（官方 Download 插件只对同源 URL 有效；跨域拿不到字节时回落 `<a download>` 浏览器默认行为），文件名从 src 路径/alt 推导；观感经 `image-lightbox.css` 用应用 shadcn 令牌（popover/radius/border）定制；**全部按钮为 shadcn Button**——经 YARL 的 `render.buttonZoom/buttonPrev/buttonNext` 与 `toolbar.buttons` 定制口替换（放大/缩小/关闭/前后切换，lucide 图标，常显深色磨砂圆底保证白图上可见；导航箭头 size-10、内收 16px，垂直居中用 wrapper flex 而非 `-translate-y-1/2`——shadcn Button 按压反馈 `active:translate-y-px` 会覆盖 translate 变量导致按钮下坠半屏；`.yarl__toolbar` 补 4px gap 统一右上角按钮间距）。src 直接取 `img.currentSrc`（渲染期已由 `resolveImageSrcSync` 解析为 asset:///data/https），图片包在 `<a>` 内时 `preventDefault` 拦导航；仅改交互不改渲染规则，standalone HTML 导出不受影响。
- 存量图片不迁移。图片存储三模式均可用。

## 6. 公共接口

```ts
interface NoteRepository {
  load(): Promise<NotebookSnapshot | null>
  save(snapshot: NotebookSnapshot): Promise<void>
}

interface ThemeRepository {
  load(): Promise<ThemeSnapshot | null>
  save(snapshot: ThemeSnapshot): Promise<void>
}

interface FileGateway {
  pickFiles(): Promise<ImportedFile[]>
  saveText(input: SaveTextInput): Promise<SaveResult>
}

/** 文件绑定双向同步 */
interface FileLinkGateway {
  readTextFile(path: string): Promise<string>
  readFolderNotes(root: string): Promise<ImportedFile[]>        // 递归读目录(打开工作区)
  writeTextFile(path: string, contents: string): Promise<void>  // Rust 原子写
  watchWorkspace(root: string | null): Promise<void>            // 工作区根递归监听,null=停止
  onFsChanges(listener: (events: FsChangeEvent[]) => void): Promise<() => void>
}

interface PdfGateway {
  print(): Promise<void>
  exportToPath(path: string): Promise<void>
  onAfterPrint(listener: () => void): () => void
}
```

实现入口：`src/modules/*/application/`、`src/modules/*/infrastructure/`、`src/platform/contracts/`。

## 7. 持久化与迁移

新协议使用独立 IndexedDB 数据库 `themd-architecture`：

```text
themd/notebook/v1（schemaVersion = 4）
themd/themes/v1
```

笔记快照只包含 `schemaVersion`、`notes`、`folders`，定位是**磁盘的缓存**：重启后按工作区记忆重扫磁盘重建。`Note.sourcePath` 为必填（v4：每个笔记都是文件），标题恒等于文件名主干；活动笔记与 `fileMissingIds`（文件失联标记）属于 UI 会话；工作区目录与最近列表在 `themd/ui-workspace/v1`。**v3：文件夹 = 磁盘目录**——`Folder {id, name, path, order}`（层级由路径前缀派生，不存 parentId），控制器在 `publish` 时惰性补建（不变式：每个笔记的目录都有 Folder 实体）。**v4：folder-first**——`titleCustom` 与库内笔记概念删除；v≤3 迁移：无 sourcePath 的库内笔记直接丢弃（用户拍板当测试数据），绑定笔记保留。主题快照只包含用户主题和 active id。编辑器默认使用打包的 JetBrains Mono（西文）与 HarmonyOS Sans SC（中文）。旧键 `md-notebook`、`themd-themes`、`themd-editor`、`themd-appearance` 不再读取——旧版数据恢复入口与 `legacy-import` 模块已删除，应用只按当前协议启动。主工作区：侧栏是固定像素宽的普通 flex 区块（`src/components/SidebarResizeHandle.tsx` 自绘拖拽条），宽度记忆在 localStorage `themd/ui-workspace/v1`（`src/app/workspace-preferences.ts`），窗口缩放零 JS 参与不抖动；侧栏**不**参与 `react-resizable-panels`——其百分比引擎在窗口缩放时靠 JS 追赶校正会产生脏帧抖动，该库现仅用于分屏视图的编辑/预览分割（shadcn `ResizablePanel`）。

设置抽屉（`src/components/SettingsSheet.tsx`）分区：主题、界面字体、编辑器。字体槽位（西文/中文）点击打开 `src/components/settings/FontField.tsx` 的 Dialog：完整本机字体列表（可搜索、逐行复制族名、点击选中）、底部自由输入框支持逗号分隔多族名（font-family 语义，浏览器按字符逐个回落）。字体枚举与可用性检测在 `src/lib/theme/font-list.ts` 与 `src/components/settings/is-font-available.ts`，共享缓存 hook 在 `src/components/settings/use-local-font-list.ts`。

## 8. Tauri 命令

Rust 命令在 `src-tauri/src/commands/` 提供包装实现，由 `src-tauri/src/main.rs` 注册；新增前端命令调用统一经 `src/platform/tauri/commands.ts`。应用为「关闭到托盘」的常驻进程，`main.rs` 第一个插件注册 `tauri-plugin-single-instance` 单实例锁——再次启动只唤起已有实例，禁止多开：

| 命令 | 用途 |
|---|---|
| `list_system_fonts` | 枚举系统字体族名 |
| `read_folder_notes` | 递归读取 Markdown 文件夹（含 `filePath` 绝对路径，非 UTF-8 不返回） |
| `read_text_files` | 读取用户选中的多个 Markdown 文件（同上） |
| `read_text_file` | 严格读取单个文本文件（绑定笔记外部改动重载用，非 UTF-8 报错） |
| `read_binary_file` | 读取二进制文件（绑定/另存为迁移 assets 图片用，与 `write_image_file` 对偶） |
| `delete_file` | 删除单个普通文件（另存为后用户确认清理原文件用；目录一律拒绝） |
| `trash_file` | 删除文件（笔记删除 = 磁盘文件移入回收站，可恢复；幂等——文件已不存在视为成功） |
| `move_note_file` | 移动文件到目标目录（「移动到文件夹」= 物理搬文件；重名自动 -2/-3 后缀，返回实际落点；跨盘回落 copy+delete） |
| `rename_note_file` | 同目录重命名文件（笔记重命名 = 磁盘文件改名；重名自动后缀，返回实际落点） |
| `rename_directory` | 重命名目录（文件夹重命名；仅同盘 rename，跨盘明确报错） |
| `delete_directory` | 删除目录（文件夹删除 = Typora 文件树语义；整棵**移入系统回收站**可恢复，`trash` crate 实现；盘符根一律拒绝） |
| `unique_destination` | 求目录下无冲突文件路径（非法字符过滤 + 重名后缀；移动即绑定/文件夹内新建用） |
| `write_text_file` | 写入 Markdown/HTML 文件（原子写：tmp + rename，失败回落覆盖） |
| `watch_workspace` | 工作区根递归监听（`commands/watch.rs`，notify `RecursiveMode::Recursive`，防抖 300ms 后 emit `fs-changed`；null = 停止） |
| `export_pdf` | 调用 WebView2 PrintToPdf |

Tauri 的托盘、窗口关闭到托盘和自定义窗口控制属于 platform 层，不进入领域模块。开机自启经 `tauri-plugin-autostart`（写 HKCU Run 键，带 `--minimized` 参数自启时窗口直接进托盘）：contract 在 `src/platform/contracts/autostart-gateway.ts`，Tauri/Web 实现装配于 `src/platform/create-platform-services.ts`，设置抽屉「主题」分区暴露开关（仅桌面端渲染，状态以系统注册表为准）。

## 12. 已知约束与坑位

- `react-resizable-panels` 仅用于分屏视图编辑/预览分割：`orientation`，百分比尺寸传字符串，像素约束传数字。侧栏不要放回它的 Group——百分比引擎窗口缩放抖动，见第 7 节工作区说明。
- shadcn 组件可能从独立 `cn` 包导入，业务代码使用 `@/lib/utils`，不要强行统一。
- `verbatimModuleSyntax` 和 `erasableSyntaxOnly` 开启，类型必须 `import type`，避免参数属性语法。
- 高亮语言按需注册，禁止改回全量 highlight.js。
- Tauri 自定义窗口使用 `decorations: false`，窗口按钮必须保持在拖拽区之外的可点击区域。
- 窗口配置 `dragDropEnabled: false`：Tauri 默认在 WebView 层拦截文件拖放（拖图片进编辑器收不到 drop 事件），关闭后由前端 `domEventHandlers` 的 drop/dragover 自行处理；设置抽屉打开时顶栏拖拽区被 overlay 遮挡，抽屉头部已补 `data-tauri-drag-region`。
- `src-tauri/gen/schemas/*` 可能因 Tauri 运行时更新，审查时区分生成物和业务改动。
- 原生右键菜单（WebView2/浏览器默认菜单）在 `src/main.tsx` 全局 `contextmenu` preventDefault 禁用（input/textarea 豁免保留原生复制粘贴）；编辑器区域的右键由 shadcn ContextMenu 接管（`EditorPane`，仅「插入图片」）。DevTools 不受影响：调试构建 F12 / Ctrl+Shift+I 打开，右键「检查」已随原生菜单消失。
- opener 插件 `open_path` 命令在 Rust 侧用 capability 里的 scope 条目构建 fs 白名单校验路径，裸 `opener:allow-open-path`（不带 scope）= 空白名单 = 任何路径都 `ForbiddenPath`；必须写成带 `"allow": [{ "path": "**" }]` 的对象权限（图片目录用户任选，不能收窄）。`reveal_item_in_dir` 不做 scope 校验，无此问题。
- 文件绑定回声抑制在**前端**：Rust watcher 不区分改动来源，应用自己写回也会触发 `fs-changed`。modified 靠「磁盘内容 = 笔记当前内容」或「= lastWritten 最近一次写回内容」过滤；**removed 事件不直接相信**——原子写的 rename 替换目标在 Windows 会被报成 removed，前端先 `readTextFile` 验证，读得到按 modified 判定、真读不到才标记失联。改这段逻辑时注意顺序（先回声后脏判定），否则编辑中会误弹冲突窗/误报失联。
- 非 UTF-8 文件不绑定（Rust `read_folder_notes`/`read_text_files` 对 lossy 解码的文件不返回 `filePath`），否则绑定写回会把降质内容写回毁掉原文件。`read_text_file` 重载同样严格 UTF-8。
- `notify-debouncer-full` 0.6 起 `Debouncer` 自带 `watch/unwatch`（`.watcher()` 已废弃返回 unit），事件结果是 `Result<_, Vec<Error>>`；notify 一律经 `notify_debouncer_full::notify` 路径引用，避免 notify 双版本类型冲突。
- 目录级 renamed 事件的判定是「严格位于 oldPath 之下」——路径完全相等是单文件重命名（标题跟随文件名），混用会导致文件重命名被当成目录处理、标题不跟随。
- `rename_directory` 只做同盘 rename；跨盘需要复制整棵目录树，明确报错而不是静默复制。`move_note_file` 跨盘回落 copy+delete（先复制成功再删源，失败时源仍在）。

## 13. 验证清单

- domain 不引用 React、Zustand、DOM、Tauri。
- 组件不直接调用 `invoke`、`indexedDB`、`localStorage`。
- 打开目录为工作区后：递归导入、新建笔记直接落盘、重命名/删除/移动全部落盘（标题恒等于磁盘文件名）、外部建/删/改经递归监听实时反映（整棵树=磁盘）。主题覆盖均能持久化；重启按工作区记忆自动重开。

## 15. 新增功能检查清单

- 先确定功能所属领域和数据流，再决定文件位置。
- 领域规则放入 `modules/*/domain`，用例放入 `application`。
- 存储和系统能力先扩展 `platform/contracts`，再实现 Web/Tauri 适配器。
- UI 通过 controller、typed command 或 `appEvents` 通信，不新增全局自定义 DOM 事件。
