# Themd 项目地图

> 给 AI 和开发者的一份速览：结构在哪、数据怎么流、样式在哪改、坑在哪。
> 产品名 **Themd**（themed + MD），包名 `themd`。

## 一句话定位

样式全由自己裁量的本地 Markdown 笔记本：左侧笔记管理，右侧 CodeMirror 编辑 + markdown-it 实时渲染（防抖 150ms），数据存 localStorage。

## 技术栈

| 层 | 选型 | 备注 |
|---|---|---|
| 框架 | React 19 + TypeScript 5.9 + Vite 7 | `create-vite@8.3.0` 官方模板（9.3.2 官方包损坏，勿升级到该版本） |
| 样式 | Tailwind CSS v4 | Vite 插件方式接入，`@plugin` 指令加载 typography |
| UI 组件 | shadcn/ui（Radix 底座 + Nova 预设） | 全部 CLI 生成于 `src/components/ui/`，可用 `npx shadcn add xxx` 继续添加 |
| 编辑器 | CodeMirror 6（`@uiw/react-codemirror` 封装） | 嵌入代码块语言按需懒加载 |
| 渲染 | markdown-it 14 + highlight.js（core + 按需 27 语言） | 任务列表用 markdown-it-task-lists |
| 状态 | zustand 5 + persist 中间件 | localStorage key：`md-notebook`（历史名，勿改，改了丢用户数据） |

## 核心数据流

**编辑 → 预览链路**（本项目最重要的链路）：

```
CodeMirror onChange
  → store.updateNote(id, content)        # zustand set → persist 自动写 localStorage
  → App.tsx useEffect 监听 active.content
      → 防抖 150ms → setPreviewText      # 切换笔记（activeId 变化）时立即刷新不防抖
  → PreviewPane 收到新 content
      → md.render(content)（useMemo 缓存）→ dangerouslySetInnerHTML → prose 排版
```

**标题自动跟随**：`store.deriveTitle()` 取正文首个 `#` 标题（否则首个非空行）。用户手动重命名后 `titleCustom: true` 锁定，不再跟随。

**视图切换**：`edit / split / preview` 三态；split 用 shadcn Resizable（react-resizable-panels v4），分割线可拖动。EditorPane 挂 `key={active.id}`，切笔记强制重挂载，避免光标和撤销栈错乱。

## 样式自设的三个层次（本项目的卖点）

主题系统已落地（详见 [主题系统设计.md](主题系统设计.md)）：内置主题 + 可视化工场 + CSS 导入导出 + 附加 CSS。

1. **改令牌/元素** → `lib/theme/elements.ts` 注册元素字段 + `styles/theme-base.css` 消费变量：加一个可定制项 = tokens.ts 加键 + elements.ts 加字段 + theme-base.css 消费，工场 UI 自动长出来。
2. **改渲染 HTML 结构** → `src/lib/markdown.ts` 的 `renderer.rules`：每种语法元素一个函数，逐个覆盖即可完全接管输出。
3. **改全局主题（应用界面）** → `src/index.css` 的 oklch CSS 变量（`:root` / `.dark`）；明暗切换由 `store-appearance.ts` 驱动 html.dark。

⚠️ 预览正文排版**不再用 Tailwind prose**，改用自建 `.themd-prose` + 令牌变量（`styles/theme-base.css`）。

## 约定与坑（改代码前必读）

- **react-resizable-panels 是 v4 API**：分组用 `orientation`（不是 v2 的 `direction`）；Panel 的 `defaultSize/minSize` 数字按**像素**解释，百分比必须传字符串（`defaultSize="50%"`），这是 4.15 的实际行为（项目地图旧版说「数字即百分比」是错的，已踩坑修正）。
- **shadcn Nova 预设组件内部** `import { cn } from "cn"`（新独立包），而业务代码用 `@/lib/utils` 的 cn——两套并存是官方现状，别"统一"它们。
- **markdown-it 类型**：默认导入只有值语义，`const md: MarkdownIt` 会报错——直接 `const md = new MarkdownIt(...)` 靠推断。
- **TS 配置严格**：`verbatimModuleSyntax` 开启（类型导入必须 `import type`）、`noUnusedLocals/Parameters` 开启。
- **新增代码高亮语言**：在 `lib/markdown.ts` 的注册表里加一行 import + 一行注册（保持按需加载，勿改回全量 `import hljs from 'highlight.js'`，主包会膨胀 2MB+）。
- **UI 组件不要手写**：缺什么 `npx shadcn@latest add <名字>`；`ui/` 下的文件可局部微调，但别大改（会被下次 add 覆盖心智）。
- **本机 Node 环境**：nvm-windows，`NVM_SYMLINK=C:\nvm4w\nodejs`（v22.14.0）。部分非交互 shell 不展开该变量，需手动 `set PATH=C:\nvm4w\nodejs;%PATH%`。

## 路线图钩子（已预留的接入点）

- 暗色模式：主题变量已就绪，只差一个切 `.dark` 的开关
- 目录/锚点跳转：标题 id 已由 renderer.rules 生成
- KaTeX / mermaid：在 `lib/markdown.ts` 加对应 markdown-it 插件即可
- 存储升级：渲染与存储相互独立，可平滑换 IndexedDB / File System Access API / Tauri
