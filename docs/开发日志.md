# 开发日志

## 2026-10-30

### 架构重构收尾

- 将应用组合层、笔记领域、主题领域、渲染、导出、平台适配和 Tauri 命令拆分到独立模块。
- 笔记与主题改由 Controller 管理，IndexedDB 通过 Repository 访问，Web/Tauri 能力通过 Platform Gateway 访问。
- Tauri 文件、字体、PDF 命令拆分到 `src-tauri/src/commands/`，入口文件只保留 Builder、插件和命令注册。
- `docs/项目地图.md` 重写为唯一权威架构说明，`README.md` 与 `AGENTS.md` 同步更新。

### 字体与界面

- 编辑器默认英文字体改为随应用打包的 JetBrains Mono。
- 编辑器默认中文字体改为随应用打包的 HarmonyOS Sans SC。
- 旧版编辑器字体偏好会在新协议水合时升级到上述默认字体。
- 主工作区恢复使用 shadcn 的 `ResizablePanelGroup`、`ResizablePanel` 和 `ResizableHandle`，保留原有比例布局与侧栏折叠交互。

- `npm run build`
- `npm run tauri:check`
